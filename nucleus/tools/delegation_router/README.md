# delegation_router

Recursive hierarchical task delegation. Splits work across hierarchy levels.

## Usage
```json
{"goal": "Analyze market for AI in Africa", "title": "system_god", "scope": {"universe": "kora-lab", "galaxy": "market-analysis"}, "max_depth": 3}
```

## Hierarchy
system_god → world_monarch → continent_emperor → country_president → ...
