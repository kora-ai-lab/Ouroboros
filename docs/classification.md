Generated by Ophidian · Phase -1

Product type: Desktop App
Interaction mode: GUI (chat, visual output) + Programmatic (OS task execution, tool creation)
Real-time: Yes (streaming LLM responses, live task execution feedback)
Multi-user content: No (personal assistant, private per-user instance)
Monetization: Freemium — free tier includes local AI + cloud augmentation (puter.js, Pollinations BYOK, BYOA); paid tier unlocks Kie AI frontier models + full BYOK flexibility; enterprise licensing for organizations
Expected scale: 100K+ users at D+90
Compliance: Comprehensive — GDPR, end-user security, zero-config security model. Users must be safe without technical knowledge.

Derived stack:
  Framework: Tauri v2 (Rust backend + React/TypeScript frontend)
    Rationale: Desktop-native window management (floating bubble overlay, global shortcuts, system tray, file system access), Rust for performance-critical LLM inference orchestration and sandboxed execution, React for reactive chat UI with streaming. Cross-platform: Windows, macOS, Linux.
  UI: React 19 + Tailwind CSS v4 + custom design system tokens
    Rationale: Highly custom UI (draggable floating bubble → expanding input → full chat container). This is NOT a standard web app layout. CSS-in-JS would add runtime overhead; Tailwind with a token system keeps the design system enforced and bundle light.
  Database: SQLite (via rusqlite, Tauri-side) + optional local vector store
    Rationale: Local-first architecture. All user data, conversation history, tool registries, and memory stay on-device. Vector store needed for semantic memory recall across years without linear storage growth. Embedded — nothing to install or configure.
  Auth: Local device profile + multi-provider OAuth (BYOA/BYOK)
    Rationale: No traditional username/password. The desktop app authenticates locally. Cloud features authenticate via OAuth to each provider: OpenAI (ChatGPT), Anthropic (Claude), Kie AI, Pollinations, etc. Paid tier manages API key vault locally.
  Hosting: Desktop distribution (Tauri MSI/DMG/AppImage bundles) + companion web API for premium tier account management, license validation, and API key proxy (optional, for privacy-preserving cloud model access)
  Tests: cargo test (Rust unit/integration) + Vitest (TypeScript unit/component) + Playwright (E2E — browser-based UI testing for the Tauri webview)

Stack override: None — all derived from product type and requirements. User confirmed stack direction via product description.
