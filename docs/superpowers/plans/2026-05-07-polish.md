## Task 1: Global Shortcut (Rust)

**Modify:** `src-tauri/src/lib.rs`

- [ ] **1A.** Add plugin + shortcut registration in `setup()`:

Current setup has 4 plugins. Add `global_shortcut` plugin after process plugin:

```rust
.plugin(tauri_plugin_process::init())
.plugin(tauri_plugin_global_shortcut::Builder::new().build())
```

After `app.manage(AppState { db: database })`, add shortcut registration:

```rust
let shortcut_handle = app.handle().clone();
app.handle().plugin(
    tauri_plugin_global_shortcut::Builder::new()
        .with_handler(move |_app, shortcut, _event| {
            if shortcut.to_string() == "Alt+Space" {
                if let Some(w) = shortcut_handle.get_webview_window("main") {
                    let visible = w.is_visible().unwrap_or(false);
                    if visible { w.hide().ok(); }
                    else { w.show().ok(); w.set_focus().ok(); }
                }
            }
        })
        .build(),
)?;
shortcut_handle.plugin(
    tauri_plugin_global_shortcut::Builder::new()
        .with_handler(|_, _, _| {})
        .build(),
)?;
```

Actually, simpler approach using the GlobalShortcutExt trait:

```rust
use tauri_plugin_global_shortcut::{GlobalShortcutExt, Shortcut};

let handle = app.handle().clone();
handle.plugin(
    tauri_plugin_global_shortcut::Builder::new()
        .with_handler(move |_app, shortcut, _event| {
            if shortcut == &Shortcut::parse("Alt+Space").unwrap() {
                if let Some(w) = handle.get_webview_window("main") {
                    if w.is_visible().unwrap_or(false) {
                        w.hide().ok();
                    } else {
                        w.show().ok();
                        w.set_focus().ok();
                    }
                }
            }
        })
        .build(),
)?;
handle.global_shortcut().register(Shortcut::parse("Alt+Space").unwrap())?;
```

## Task 6: Dual Monitor

**Modify:** `src/hooks/useBubble.ts`

- [ ] **6A.** Add dual monitor awareness:

In the initial position calculation, use `window.screen.width/height` and `window.screenX/screenY` to compute center of current monitor. Place bubble near bottom-right of that monitor.

Simple approach: in Rust, after creating the main window, position it at bottom-right of the primary monitor. The bubble hook's drag will override this on subsequent launches.

In `lib.rs` setup:
```rust
if let Some(main) = app.get_webview_window("main") {
    if let Some(monitor) = main.available_monitors().ok().and_then(|m| m.into_iter().next()) {
        let size = monitor.size();
        let pos = monitor.position();
        main.set_position(tauri::PhysicalPosition::new(
            pos.x + size.width as i32 - 60,
            pos.y + size.height as i32 - 120,
        )).ok();
    }
}
```
